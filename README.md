# Проект electronic_sale_net . Онлайн платформа-торговая сеть электроники

### Технические требования

* Python 3.8+
* Django 3+
* DRF 3.10+
* PostgreSQL 10+


### Задание

Сеть представляет собой иерархическую структуру из трех уровней:
* завод;
* розничная сеть;
* индивидуальный предприниматель.

## Функционал:
* Реализованы модели сети
* Каждое звено сети обладает определенными элементами
* Реализован вывод созданных элементов в админ-панели
* Реализован CRUD для модели поставщика
* Настроены права доступа к API так, чтобы только активные сотрудники имели доступ к API.
